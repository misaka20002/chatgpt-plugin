# 角色动图回复

Bot 主人可以在插件外用自己的 GPT Image 2 API 制作三张基础图和最多 32 张特色图，经 [Peraravatar+](https://gyungyun.com/peraravatar-plus/) 配置，保存网站导出的 JSON。插件在本地控制图片切换和动作，为正式回复生成带短气泡的 GIF。

这是完整立绘切换的 PNGTuber 动画，支持眨眼、模拟嘴型、呼吸、摇摆和特色动作；输出为透明背景 GIF。启用后每轮先发完整文字，再附带一张动图；GIF 无声音。现有语音、图片模式继续工作。辅助模型会额外调用一次「短句模型来源」配置的提供商（默认跟随本轮实际使用的条目），生成短句和动作，不调用工具、不另设回复 token 上限。

## 1. 准备图片

使用自己的图片编辑 API，模型选择 **gpt-image-2**，大小 **1024x1024**。先制作正常图，再将这张正常图作为其他差分的参考图片，避免独立生成导致人物位置、比例、服饰变化。

| 文件建议命名 | 内容 | 必需 |
| --- | --- | --- |
| normal.png | 睁眼、闭嘴 | 是 |
| close.png | 闭眼、闭嘴 | 是 |
| open.png | 睁眼、小幅张嘴 | 是 |
| happy.png | 开心的完整立绘 | 否 |
| confused.png | 困惑的完整立绘 | 否 |
| angry.png | 生气的完整立绘 | 否 |
| shy.png | 害羞的完整立绘 | 否 |
| crying.png | 哭泣的完整立绘 | 否 |

上表的五种特色表情是候选素材库，可以全部放进同一个角色配置。插件支持三张基础图＋最多 32 张特色图，同时受资源大小和累计像素限制。开心、困惑、生气、害羞、哭泣都不是插件硬编码的表情枚举；插件根据网站导出的表情 ID 选择图片，表情名称用于帮助模型理解。

所有图片保持相同画布、人物位置、大小、姿势。推荐最终图片使用透明背景 PNG（GIF 输出为透明背景，透明 PNG 才能让背景真正透明；纯白背景图片在 GIF 中仍会显示白色底），且 **GPT Image 2 不直接请求透明背景**；不要传 background=transparent 或 input_fidelity。不同服务的图片编辑接口字段可能不同，参考图片需按所用服务的接口上传，下面是提示词而非固定 HTTP 请求格式。

### 正常图提示词 normal.png

将参考图片制作成用于群聊角色动图的基准立绘，输出 1024×1024 的单张图片。保留参考角色的身份、Q 版比例、脸型、发色、发型、帽子、发夹、服饰、配色和画风。角色睁开双眼，嘴巴自然闭合，表情亲切。使用纯白背景，人物居中，头部和帽子完整可见，边缘留出空白，下方可保留半身裁切。确定人物位置、大小、姿势与头部倾角，后续差分都将沿用这张图。画面只包含一个角色，不添加文字、标志、边框或额外装饰。

### 闭眼图提示词 close.png

这张参考图是已经确定的角色基准图。请制作同画布的闭眼差分，输出 1024×1024 单张图片。只把双眼改成自然闭合的眨眼状态，保持闭嘴。严格保持人物位置、比例、姿势、头部倾角、帽子、发夹、头发轮廓、服饰、光照、线条、配色和纯白背景不变。不得重新构图、放大、缩小或移动角色，不改动其他部位，不添加文字。目标是与基准图切换时，除了眼睛之外其他像素区域尽可能一致。

### 张嘴图提示词 open.png

这张参考图是已经确定的角色基准图。请制作说话差分，输出 1024×1024 单张图片。只将嘴巴改成自然说话时的小幅张嘴，画出合理的小口腔，双眼保持睁开。严格保持人物位置、比例、姿势、头部倾角、帽子、发夹、头发轮廓、服饰、光照、线条、配色和纯白背景不变。不得重新构图、放大、缩小或移动角色，不改变脸型，不添加文字。目标是与基准图切换时，除了嘴巴之外其他像素区域尽可能一致。

### 开心图提示词（可选） happy.png

以这张角色基准图制作开心表情的完整立绘，输出 1024×1024 单张图片。只修改面部表情，让眼睛和嘴巴呈现自然、可爱的开心笑容。严格保持人物位置、比例、姿势、头部倾角、脸型、帽子、发夹、头发轮廓、服饰、光照、线条、配色和纯白背景不变。不得重新构图、移动角色或添加文字。此图会作为一张完整特色表情播放，而不是眼睛或嘴巴部件。

### 困惑图提示词（可选） confused.png

以这张角色基准图制作轻微困惑表情的完整立绘，输出 1024×1024 单张图片。只修改眉眼和嘴巴，表现温和的疑惑感，不改变脸型和人物姿势。严格保持人物位置、比例、头部倾角、帽子、发夹、头发轮廓、服饰、光照、线条、配色和纯白背景不变。不得重新构图、移动角色、添加问号或文字。此图会作为一张完整特色表情播放。

### 生气图提示词（可选） angry.png

这张参考图是已经确定的角色基准图。请制作可爱、轻微生气的完整立绘差分，输出 1024×1024 单张图片。只修改面部：眉毛略向内收拢，眼神稍微不满，嘴巴自然抿起或呈小小的嘟嘴，保留角色原来的亲和感，不做夸张狰狞表情。严格保持人物位置、比例、姿势、头部倾角、脸型、帽子、发夹、头发轮廓、服饰、光照、线条、配色和纯白背景不变。不得握拳、改变身体动作、重新构图、放大、缩小或移动角色；不添加怒气符号、火焰、烟雾、文字或额外道具。此图作为完整特色表情播放，不是五官部件。除指定面部区域外，其他区域应尽可能与基准图一致。

### 害羞图提示词（可选） shy.png

这张参考图是已经确定的角色基准图。请制作温柔、可爱的害羞完整立绘差分，输出 1024×1024 单张图片。只修改面部：眉眼稍微柔和，目光略显羞涩，嘴巴为自然的小幅闭嘴微笑，脸颊增加轻柔的粉红晕染。保持原来双眼的颜色和结构，不改变脸型。严格保持人物位置、比例、姿势、头部倾角、帽子、发夹、头发轮廓、服饰、光照、线条、整体配色和纯白背景不变。不得转头、低头、抬手遮脸、重新构图、放大、缩小或移动角色；不添加爱心、汗滴、文字或额外道具。此图作为完整特色表情播放，不是五官部件。除指定面部区域外，其他区域应尽可能与基准图一致。

### 哭泣图提示词（可选） crying.png

这张参考图是已经确定的角色基准图。请制作委屈、轻声哭泣的完整立绘差分，输出 1024×1024 单张图片。只修改面部：眉毛略显委屈，双眼含泪，在眼角与脸颊添加少量自然的小泪珠，嘴巴微微下弯，保留可爱、柔和的角色气质。泪珠局限在面部区域，不画夸张的喷泉式眼泪，不改变眼睛颜色和脸型。严格保持人物位置、比例、姿势、头部倾角、帽子、发夹、头发轮廓、服饰、光照、线条、整体配色和纯白背景不变。不得抬手擦泪、改变身体动作、重新构图、放大、缩小或移动角色；不添加雨滴背景、乌云、文字或额外道具。此图作为完整特色表情播放，不是五官部件。除指定面部区域外，其他区域应尽可能与基准图一致。

### 表情名称与动作搭配

| 候选图片 | 网站表情名称建议 | 动作建议 |
| --- | --- | --- |
| happy.png | 开心：高兴、庆祝、赞美 | bounce 或 nod |
| confused.png | 困惑：疑问、不确定、思考 | wobble |
| angry.png | 生气：不满、抱怨、轻微恼怒 | shake 或 headshake |
| shy.png | 害羞：羞涩、腼腆、被夸奖 | wobble 或 none |
| crying.png | 哭泣：委屈、难过、伤心 | shake 或 none |

建议保留网站自动生成的表情 ID，不要把 ID 改成中文；中文描述填写在表情名称中。插件接受的 ID 为 1～80 个英文字母、数字、下划线或连字符，且不能重复。这些动作是整体立绘的运动，不会让泪珠、头发等部件独立运动。名称和动作搭配是建议，可以自行修改。

### 检查对齐

在图片编辑器中将差分叠在 normal.png 上，以 50% 不透明度检查；帽子、发夹、肩膀、衣服和头发边缘应重合。快速切换图片时这些部位不应抖动。若漂移明显，重新用正常图编辑差分；仅整体移动或缩放时，也可以在网站的“位置与大小”中修正。插件保留网站的图片位移、缩放和旋转配置，不能自动修复局部结构变化。

## 2. 在网站配置并导出

以下按网页当前界面列出原文，统一格式为 **日语原文**（英语原文/中文含义）；按照自己页面显示的语言找按钮即可。

1. 打开 [Peraravatar+](https://gyungyun.com/peraravatar-plus/)，点击标签栏的 **画像**（Images/图片） 页签。在 **作り方を選ぶ**（Choose how to build/选择制作方式） 中选择 **各画像を用意する**（Prepare each image/分别准备完整图片）。不要选择 **1枚絵から作る**（Build from one image/从一张图拆部件制作）。
2. 在 **音量で決める**（By volume/根据音量决定口型） 选项上点击，将口型模式改为音量模式；不要选 **母音で決める**（By vowel/根据元音决定口型）。
3. 找到 **通常**（Normal/正常） 图片槽位，点击其图片区域选择 normal.png；再找到 **瞬き（閉じた目）**（Blink (eyes closed)/眨眼／闭眼） 槽位，点击图片区域选择 close.png。然后分别点击 **クリア** 移除 **寝ている**、**よそ見（左）**、**よそ見（右）** 的默认图片。
4. 网页下拉，在口型区域找到 **口 段階1**（Mouth stage 1/口型第 1 档）。对多余的档位点击该档标题右侧的 **削除**（Delete/删除），只保留一档。档内已有图片时，可以点击图片缩略图替换为 open.png；若一档有多张图片，点击多余缩略图上的 **×**（删除该图片），只留一张。

---

5. (可选) 网页继续下拉，找到 **カスタム表情（ホットキーで切り替え）**（Custom expressions (switch with hotkeys)/自定义表情，通过快捷键切换）区域。先点击每张网站默认表情卡片的 **削除**（Delete/删除），清除默认表情。然后按下面对应步骤创建自己的表情。

### 配置开心表情 (可选)

1. 点击 **+ 表情を追加**（+ Add expression/添加表情），创建一张新的表情卡片。
2. 卡片左侧的虚线方框中有 **＋**（上传表情图片），直接点击它选择完整立绘。
3. 在文件选择窗口中选中 **happy.png**。上传完成
4. 找到名称输入框，将内容填写为 **开心：高兴、庆祝、赞美**。保留网站自动生成的内部 ID；名称可以使用中文。
5. 找到名称输入框下方、**Z** 等快捷键按钮右侧的下拉框，初始显示 **動かない**（None/不运动）。点击该下拉框，选择 **バウンス（軽く上下に弾む）**（Bounce (light hops)/轻微上下弹跳）。注意选择的是当前表情卡片的动作，不是上方角色整体的口型或动作模式。
6. 点击卡片右上方的 **プレビュー**（Preview/预览）检查图片。若图片局部或整体明显错位，先修正素材；只有页面实际提供 **位置と大きさ**（Position & size/位置与大小）时再用它调整，不需要在当前截图的卡片中寻找该按钮。

用于高兴、庆祝成功或夸奖的回复。

6. 点击标签栏的 **書き出し**（Export/导出） 页签，向下找到 **設定の移行・バックアップ**（Transfer & backup/配置迁移／备份），点击 **JSON をファイルで書き出し**（Export JSON file/将配置导出为 JSON 文件），下载 peraravatar-plus-config.json。不要点击 **アバターを HTML で書き出し**（Export avatar as HTML/将角色导出为 HTML），插件需要的是 JSON。

> 按钮名称核对自[网站界面](https://gyungyun.com/peraravatar-plus/)及其[日语词条](https://gyungyun.com/peraravatar-plus/locales/ja.js)、[英语词条](https://gyungyun.com/peraravatar-plus/locales/en.js)。浏览器自动翻译可能改写按钮名称，找不到原文时可先关闭网页翻译。
> 
> 网站的默认口型和特色表情通常多于首版支持范围，必须按上述步骤删去多余条目。导出的正常、闭眼、张嘴和特色图片应为 data:image/...;base64,... 内嵌数据，不能引用网站样例或外部网址。
> 
> 首版支持 schema:2、imageMode:images、一个开口档和最多 32 种特色表情。闭眼优先于开口；特色表情显示期间暂停眨眼和嘴型。睡眠、侧视、分层、装饰部件、麦克风追踪、摄像头追踪和弹性模拟不启用；导出文件中闲置的分层／侧视样例字段不会被加载。网站的播放效果与插件按群配置的动作时长不完全相同。
> 
> 读取限制：JSON 最大 32 MiB；每张有效图片最大 6 MiB，最长边 2048 像素，累计图片最多 32 MiPixels；只接受静态 PNG、JPEG、WebP。图片必须包含真实的对应格式。图片位移限制为 ±2048、缩放 0.1～3、旋转 ±180°；动作幅度最多 30，周期 100～30000 毫秒。眨眼最短间隔至少 100 毫秒，最长间隔不能小于最短间隔，闭眼时长为 100～1000 毫秒。

## 3. 放置网站导出的 JSON

本文保留手工网站制作流程。自动生成 JSON、多角色下拉和分辨率／时长／FPS 设置，请阅读独立的[图片文件夹与多角色说明](avatar-reply-auto.md)。

将网站下载的 peraravatar-plus-config.json 放在 **Yunzai 根目录**下的 data/chatgpt/avatars/角色目录名/peraravatar-plus-config.json（目录名就是锅巴下拉里显示的角色名，可用中文）。重新加载锅巴配置页面，在“角色动图群”中填写 Bot QQ 和群号，角色文件夹选择该目录，再开启对应群。私聊预览/状态使用群号 8888 的保留行，打开该行开关后私聊回复也会自动附图，详见[图片文件夹与多角色说明](avatar-reply-auto.md)。

Bot 主人可以在群内发送 #chatgpt角色状态 查看图片数量、表情名称和读取错误；发送 #chatgpt角色预览 检查布局、基础眨眼和嘴型。预览使用固定短句，不调用辅助模型，不能证明模型已经选中过特色表情。

替换网站 JSON 后，在下一次使用时检查文件更新。更新失败会保留本进程中该角色上一次成功加载的资源，请查看状态中的错误；重启不能恢复仅在内存中的旧资源，请自行保留备份。

默认仍为 512×640、3秒、10 FPS；画质档位和排障方法见[新版说明](avatar-reply-auto.md#2-输出与排障)。图片对齐、中文字体和实际 QQ 动图上传效果需在自己的运行环境中检查。
