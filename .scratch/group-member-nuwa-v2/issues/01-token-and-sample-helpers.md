# 01 token 计量与样本整理纯函数

Status: done

## 目标

把「字符」换成「token」这一步的基础件做完，供后续票复用。

## 范围

- 抽出全仓唯一的近似 token 估算函数：中文（含扩展 A）1.2 字/token、其他 4 字/token、向上取整；记忆提炼与压缩改为从新模块导入，不再各自持有。
- 群友 Skill 常量改为 token：输入预算 100000、单块 50000；新增默认消息数 500 与参数上限 2000 两个值。
- 分层抽样按 token 计算，超预算时等距抽样保时间跨度。
- 切块按 token 累加（含证据 ID 与日期的行宽）；单条超预算时仍单独成块。
- 新增纯函数：本地与历史记录合并去重（消息 ID / 内容摘要 / 文本三级）、从原文占位符推导媒体事件与目标消息时间线。

## 验收

- 记忆相关的既有测试全绿（token 函数搬家没有改变行为）。
- 上述纯函数有直接单测覆盖，见票 06。
