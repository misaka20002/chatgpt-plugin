# 03 生成物结构与质量自检

Status: done

Blocked by: 01

## 目标

让生成的 SKILL.md 具备上游的可操作性，并在交付前做确定性自检。

## 范围

- 合成提示词新增可选输入：已存事实背景段、上一次同目标产物（增量更新）、重跑修正指令。
- 合成输出新增 `research_dimensions`（≤5 条，每条含维度与关注点），服务端规范化：空字段丢弃、超长截断、超量截断。
- 新增质量自检纯函数：心智模型 3-7 个、每个有失效条件、表达 DNA ≥3 项、诚实边界 ≥3 条、内在张力 ≥2 处；返回失败项列表。
- 新增修正反馈文本生成函数（把失败项写成给模型的修正指令）。
- 渲染新增：角色扮演规则（首次免责 + 「未表态主题标推断」+ 「关键引用可分辨」+ 退出语）、身份卡、回答工作流（问题分类 → 研究维度 → 回答）、数据构成；自检未通过时诚实边界追加未过项。
- 渲染不引入时间线与智识谱系。

## 验收

- 生成物包含上述段落且不含时间线/谱系。
- 自检对合格与各类不合格产物分别给出预期结果。
- `research_dimensions` 的规范化有直接单测。

## Comments

- 回答工作流的 Step 2 只给「从心智模型推导」的规则与本次推导结果，不硬编码通用维度。
