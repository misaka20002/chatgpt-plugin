# 02 本地记忆样本与回退编排

Status: done

Blocked by: 01

## 目标

群已授权记忆采集时优先用本地样本，不足再回退历史扫描。

## 范围

- 新增「已存个人事实」选择纯函数：只读本群 `user_group` 作用域，过滤归档与已过期，按重要性/置信度/更新时间排序，`factKey + text` 去重，按 40 条、4000 字双上限截断。
- 采集编排：记忆总开关 + 群授权都满足才读本地；本地原文用「最近原文」接口（20000 条上限）按保留天数回推时间窗，按发送者过滤、跳过指令与空文本。
- 本地目标消息 ≥30 条时完全不调用历史接口；不足时只补差额，合并去重后按时间取最近 N 条。
- 纯本地路径用占位符推导媒体事件；执行过历史扫描时沿用扫描结果，避免同一条消息被计两次。
- 日志沿用 `[GroupMemberSkillTool]` 前缀，分别记录本地取样条数与回退原因。

## 验收

- 本地够 30 条时历史接口零调用（以假适配器断言）。
- 本地不足时合并结果不超过请求条数且无重复。
- 其他群与私聊的事实不会出现在输入里。

## Comments

- 事实只作合成背景，不产生证据 ID，也不进证据文件。
