# 04 工具编排：落盘断点、失败报告、增量更新、参数上限

Status: done

Blocked by: 02, 03

## 目标

把新能力接进工具主流程，并让失败可诊断。

## 范围

- 运行目录在分块分析前创建；每块成功即写 `references/research/chunk-NN.json`。
- 去掉临时目录 + 重命名，改为直接写入技能目录；缺少 SKILL.md 即代表未完成。
- 失败路径写 `references/generation-report.json`（状态、错误、块统计），错误信息带产物目录。
- 合成后跑质量自检；不通过带失败项重跑一次，失败项更少才替换；仍不通过继续交付并在报告与诚实边界标注。
- 生成前读取同目标最近一次运行的 SKILL.md（截断 12000 字）作为增量更新上下文。
- 报告新增每块 token 数、输入 token 估算、质量自检结果；不新增来源字段。返回摘要加自检结论。
- 工具参数 `max_msg_count` 上限 2000、默认 500，描述同步。
- 清理未使用的导入。

## 验收

- 单块连续失败时其余块仍落盘、报告记录失败数。
- 合成失败后磁盘上仍有分块文件与失败报告。
- 自检失败只重跑一次。
