# 群聊自主回复交流对象识别

Status: ready-for-agent

## 目标
仅在群聊自主回复的正式模型请求中，于现有系统提示词末尾追加以下本轮场景说明：

> 【群聊自主回复】
> 本次回复由群聊自主回复触发，不代表群友正在与你对话。请结合群聊历史、@和引用，判断待回复消息是对谁说的；对象不明时，不要默认是你。若消息是对他人说的，可以第三方身份自然参与，但不要冒认他人的身份、发言或行为。不要输出判断过程。

## 边界
- Q1-Q5 已确认：仅自主回复、允许自然第三方参与、不添加 NO_REPLY、复用现有配置的群聊历史、原有人设系统提示词保持且附加说明放在末尾。
- 复用 apps/chat.js 的 automatic && e.isGroup，传递本轮上下文至 model/core.js。覆盖 OpenAI Chat Completions / Responses / Claude / Gemini 四类请求。
- 不改自主触发概率、选择和速率限制；不改历史数量/加载方式；不新增模型调用；普通群聊、命令、@、私聊无影响。
- 本轮提示词不写回会话历史，重试/同协议备用仍携带一次，不跨轮泄漏。

## 验证
- 实际请求系统提示词末尾附加一次；普通聊天不存在此指令。
- 已有入口与四 provider 请求测试覆盖；运行专项及可运行的全量回归，无法执行则如实报告。
- 开发与测试阶段不部署、不重启，也不擅自提交或推送；只修改本插件。
- 后续用户已明确授权：将本功能经验证的改动提交并推送至 `misaka20002/chatgpt-plugin` 的 `v2` 分支；仍不部署或重启服务。
