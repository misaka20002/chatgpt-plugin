# 02: 引用的合并转发在入 core 前自动展开

**What to build:** 用户引用一条合并转发时，Bot 在组装 prompt 前读到它的内容，按「引用文本 → 引用转发 → 用户正文」的顺序交给模型；读取失败时让模型明确知道没读到。

**Blocked by:** 01（合并转发读取与渲染模块）

**Status:** done

- [x] 引用解析时收集被引用消息里的 forward id（只收集、不拉取）
- [x] 无 forward 段时零额外接口调用、零提示行
- [x] prompt 顺序为「引用文本 → 引用转发 → 用户正文」
- [x] 适配器不支持 / 超时或异常 / 空转发各给一行不同的中文提示
- [x] 展开结果不写入 Web 对话记录用的消息备份
