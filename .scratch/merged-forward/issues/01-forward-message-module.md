# 01: 合并转发读取与渲染模块

**What to build:** 给定事件与一个 forward id，拉取该合并转发的节点，渲染成 Markdown 引用块，并在过程中执行条数/字符/嵌套/超时预算与媒体地址收集。引用路径与工具路径都只依赖这一个模块。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 群聊与私聊分别从事件上取拉取能力；两者都没有时抛出「适配器不支持」类错误
- [x] 节点渲染成 `昵称(QQ)：内容`，文本/图片/视频/语音/文件/卡片/表情/at/回复各有确定形态
- [x] 图片与视频的 http(s) 地址以 Markdown 链接给出；无地址时退回占位符
- [x] 嵌套转发只展开 1 层，再深输出 `[合并转发]` 占位
- [x] 节点 50、字符 20000、单次拉取 10 秒；超限明确标记
- [x] 返回媒体地址列表，只含 image/video 段的 http(s) 地址
