# 04 指令入口：确认门、并发与投递

Status: done

Blocked by: 01, 03

## 目标

`#女娲蒸馏` 能在一个群里被主人触发，先讲清代价再执行，产物默认发私聊。

## 范围

- 指令并入 `apps/atGraph.js`（第二个 rule，`permission: 'master'`），只在群聊可用；开关关闭、目标不合法时给明确原因。
- 确认文案按 spec 定稿渲染：昵称、QQ、提供商标签、保留天数都取实时值。
- 确认门 180 秒；`!e_new` 回「确认超时，已取消」，非确认词回「已取消」；确认后复查开关。
- 模块级 `Set` 按群号互斥，`finally` 释放。
- 投递：`e.bot.pickFriend(e.user_id).sendFile()` 优先，抛错回退当前群；仍失败则 `SKILL.md`；两级都不成时由摘要说明「附件发送失败」并给产物目录（没有第三级文本投递）。
- 摘要：样本条数、置信度、模型/启发式/表达 DNA 数量、自检结果、耗时、产物目录、ZIP 去向。

## 验收

- 非主人触发由框架拒绝，处理函数不被调用。
- 开关关闭时不出确认文案。
- 同群第二次触发在第一次未结束时回「已有任务在跑」。
