# 使用设定：本地设定数字菜单

Status: ready-for-agent

## 目标

`#chatgpt使用设定` 不带设定名时，像 `#chatgpt切换模型` 一样先列出本地 `prompts/*.txt` 的设定名，
用序号让主人选择，再把选中设定的正文写入**当前默认模型**的系统提示字段，使其对后续对话生效。

## 决策（本轮逐条确认）

- Q1 触发形态：裸指令弹菜单；`#chatgpt使用设定<名字>` 保持直接应用；纯数字参数按名字解释，不当序号。
- Q1 补充：`#chatgpt导入设定`（云端设定站已下线）不再作为「名字找不到」的回退路径；名字不存在时直接提示，
  并指向裸指令看本地列表。`#chatgpt设定列表` 本身是纯本地读取（`readPrompts()`），不是云端功能，本次保留不动。
- Q2 菜单条目：只列本地 `prompts/*.txt`，按名字排序；不列 `API默认` / `Sydney默认`——它们的内容就是被上一次
  应用覆盖的那个字段，列出来等于自我引用，且 bing 模式已不存在。
- Q3 覆盖保护：当前字段非空时，覆盖前询问一次：`0`（`取消`/`退出` 同义）取消、`确定`（`覆盖`/`直接覆盖` 同义）
  直接覆盖、其它内容作为备份设定名（先把当前字段存成新的本地设定再覆盖）。备份名去掉重复的 `.txt` 扩展名后，
  为空、超过 40 字、以 `.` 开头、含路径/系统字符、或已存在同名设定时取消整个操作。
  当前字段为空时没有可覆盖的内容，直接应用不询问。
- Q3 顺序：设定存在性检查在备份落盘之前，确认阶段设定被删则整单取消、不留备份文件。
- Q4 「当前使用」标记：不做模糊匹配。先找**正文规范化后全文相等**的（CRLF→LF、去尾部空白），完全相同的有几份就标几份；
  一份都不相等时，再按 `当前值` 以 `设定正文 + 换行` 开头匹配（azure 语音应用时会追加情绪提示），
  并且只认最长的那一份，避免一份设定恰是另一份前缀时两边都标。判定不看当前是否仍开着 azure，否则关掉语音后标记就没了。
  不读 redis 的名字记录，因为锅巴或 `#chatgpt设置设定` 改过字段后那条记录会说谎。
- Q4 菜单排版：一行一个名字，超过 30 条时追加一句「也可以直接发送 #chatgpt使用设定<设定名>」，
  序号仍覆盖全表（否则后面的选不了）。
- 附带修正：`readPrompts()` 原来用 lodash `trimEnd(file, '.txt')` 取名字，第二参被当成字符集合，
  会削掉名字结尾的 t/x/.（`cat.txt` → `ca`），菜单显示错名字；改为只替换 `.txt` 后缀，并按名字排序保证序号稳定。
- Q5 写入方式：用 `updateProvider(默认行.id, { [PROMPT_FIELDS[type]]: 正文 })` 显式写默认模型所在行，
  取代 `Config[keyMap[type]]` 的 Proxy 隐式写入；删掉不可达的 `bing`/`sydney` 分支与「该模式不支持设定」提示。
  保留 azure 情绪追加与 `CHATGPT:PROMPT_USE_<协议>` 记录；后者只是「上传设定」的记账，写在配置落库之后，
  失败只记 `logger.warn` 不回主人——它丢了不影响已生效的设定。
  **后续（2026-10-27）**：这条记录已随云端设定功能下线一并移除写入，见 `.scratch/prompt-delete-menu/spec.md`。
- Q6 菜单实现：抽 `utils/menu.js`，`ProviderManagement.choose` 与设定菜单共用同一份序号/取消/超时/同发送者校验。
- 文案同步：`apps/help.js`、`resources/help.json`。

## 边界

- 不改云端相关指令（`导入/浏览/预览/上传/删除共享设定`）的实现，只让 `usePrompt` 不再调用它们。
- 不改 `#chatgpt添加设定` / `#chatgpt查看设定` / 锅巴字段与默认值。
- 设定写入目标固定为指令执行时解析到的默认模型行；等待期间若他人切换主模型，仍写入确认文案里显示的那个。

## 验证

- 新增 `test/promptMenu.test.mjs`，挂进 `test:providers`：菜单列出本地设定、序号应用写入默认行（api 与 gemini 各一例，
  证明写的是默认行的对应字段）、名字直用不弹菜单、`0` 取消、`确定` 覆盖、备份名落盘、非法/重名备份名取消、
  超时与他人代答不写入、空字段不询问、超过 30 条的提示、「当前使用」按正文标注（含 azure 后缀、关掉语音后仍标）。
- `npm run check`（语法预检 + 路径卫生 + 风格 + 快套件）。
- 不改 `apps/button.js`：它发的是裸指令，本次改动后正好变成可用菜单。
