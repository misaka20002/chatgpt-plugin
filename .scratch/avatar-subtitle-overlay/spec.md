# 角色动图：电影字幕叠加层（已确认需求）

Status: ready-for-human

本地开发与回归已完成；尚未提交或合入，等待维护者审阅及 QQ 客户端自动下载验收。

## 目标与已确认决策（Q1～Q17）

- **替换旧气泡**：把浅色带箭头的气泡换成电影/视频字幕。字幕是角色画面**前景图层**中的文字，位于**画面内底部居中**，不是画面顶端，也不是另辟一块底部留白区；允许字幕直接盖住下部角色图像。只留少量防裁切边缘间距，不设置独立的“字幕安全区”或背景底条。（Q1、Q2、Q13）
- **外观**：白色字、黑色描边、轻微阴影；没有气泡、边框、箭头、半透明黑底条。（Q2）
- **范围**：完全替换旧样式，预览、群聊和私聊统一效果；不增加风格切换开关。（Q3、Q10）
- **时间轴**：每次画面**只有一行、一段字幕**，当前段完整显示一段时间后，下一段直接切换；不同时显示两行，不逐字出现，不做渐变。（Q4、Q14）
- **分段来源**：辅助模型优先直接返回有自然语义断句的字幕段数组；最多 **2 段**、每段最多 **12 个可见字素**，总计最多 **24 个可见字素**。从完整回复中提炼有意义的短句而非全文照搬；不因此增加额外模型调用，也不影响原始文字回复。（Q5～Q7、Q16）
- **时间分配**：一段字幕显示 GIF 全程；两段时每段**至少显示 0.7 秒**，在扣除各段最低时长后，将剩余时间按各段可见字素数比例分配。最终按 GIF 帧边界取整且保证总帧数不变，不出现空白字幕帧。（Q8、Q15）
- **容错**：模型返回段落格式不合规、文本超长或缺乏合适分段时，由本地整理阶段在不额外请求模型的情况下兜底：优先从原回复首句提取短句，按标点断句、不足时按可见字素数切分；仅保留有意义的前两段（每段不超过 12、总计不超过 24 个字素）；**切分后清理每段首尾标点**，不显示纯标点或空段。（Q12、Q16）
- **尺寸与布局**：旧**最低档** `512×640` 改为 `512×512`，其他档 `768×768`、`1024×1024` 保持不变；所有输出 GIF 都是**正方形**。缺省尺寸改为 `512×512`；原配置中已保存的 `512×640` 选择按新最低档迁移，不影响已选择 `768×768` 或 `1024×1024` 的配置。取消为气泡单独留出的画布区，**适度放大角色**且保留头部完整，字幕直接覆盖在角色下部。（Q9、Q11）
- **典型用户配置及体积目标**：用户通常选择 `768×768`、`3 秒`、`10 FPS`，是其 QQ 环境中实测能自动下载 GIF 的最大实用组合。不得改动该配置或增加无必要的渲染开销；须对比修改前后 GIF 体积并尽可能保持自动下载行为，最终需要 QQ 实际客户端验证（不能仅凭项目自身 8 MiB 上限推断 QQ 下载阈值）。
- **其他保持不变**：既有角色素材、嘴型/眨眼、表情过渡、动作、预览与正式发送、安全转义、尺寸以外的时长/帧率配置和失败处理流程。

## 字幕排版与边界规则

1. **单行适配**：默认使用清晰可读的较大电影字幕字号，依据**实际文字宽度**缩小字号；不按字数粗略估宽、不自动换行。达到可读性下限后仍超宽，安全截短字幕内容，使其保留在画面内；正确处理中文、英文、emoji 与组合字素。（Q17）
2. **字幕坐标**：三档均按正方形画布比例确定底部居中位置，仅保留防止文字和描边被裁切的最小外边距；**不是**角色不能进入的独立字幕区。字幕绘制在角色、表情与动画图层**上方**。（Q1、Q9、Q13）
3. **切换边界**：字幕段随帧数顺序显示，不叠两段、不引入额外过渡帧、不改变角色眨眼或动作时间线；两段均至少 0.7 秒。（Q4、Q8、Q14、Q15）
4. **失败语义**：无论字幕生成、切段还是 GIF 附图失败，既有完整聊天文字仍正常发送；保留原先安全转义、任务队列、超时和 GIF 体积限制。（Q12、Q16）

## 验收方向

- 三档画布/输出 GIF 都为正方形；底部文字在画面之上，最多一行，不出现旧气泡。
- 两段按顺序单行轮播、每段至少 0.7 秒，剩余时间按字素数分配；切段后首尾无残留标点，不能有空段或纯标点字幕。
- 模型优先产出最多两段 JSON 字幕数组，无法使用时本地兜底，不新增模型调用；总量最多 24 字素，每段最多 12 字素。
- 长英文或 emoji 情况下逐段自适应字号，保证完整位于画面宽度内，不自动折为两行。
- 768×768/3 秒/10 FPS 的体积需实测，并关注 QQ 自动下载阈值，不牺牲原有默认聊天文字。
- 不改变角色动画和表情过渡，不改变群聊/私聊权限、队列、超时、输出大小护栏及文本安全转义。
- 验证白底和透明底素材、不同字符宽度与字号下的可读性。
