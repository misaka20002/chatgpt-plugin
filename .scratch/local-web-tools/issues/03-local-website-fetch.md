# 03: 网页读取工具改纯 HTTP + Markdown

**What to build:** 锅巴里的「呆毛纯本地网页读取工具」不再启动浏览器。选中它之后，模型给一个 URL 就能拿到 Markdown 正文，长文会给出续读偏移；没有 Chromium 的机器也能用，读网页也不会再把插件自己的渲染器关掉。

**Blocked by:** 01（本地取页模块与转换器）

**Status:** done（2026-10-21）

- [x] 没有 Chromium / puppeteer 的环境下能读取正常页面；输出复用统一契约（`Provider / URL / Title` 头 + 不可信声明 + 20000 字符 + 截断标记）
- [x] 按截断标记里的 `start` 再调一次，能拿到后续片段；越界 `start` 显式失败
- [x] 彻底删除 puppeteer 通道与正则清洗：读网页不再连接或关闭共享 Chromium，也不再改动全局 `headless`
- [x] 403、空正文、非文本内容、私网目标都返回带原因的 `Error:`，不返回「读到了但内容是空」的假成功
- [x] 工具描述写明兜底定位：不支持 JS 渲染与登录墙，需要更高质量时改用 Exa / Parallel 读取
- [x] 最小测试并接进 `test:tools`：契约头与续读一条、私网地址被拒且不发出请求一条
